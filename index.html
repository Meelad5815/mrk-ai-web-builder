Safety rules

Built for secure website automation.

  • Never expose Gemini API keys, OAuth secrets, or database passwords.
  • Prefer OAuth or GitHub Apps instead of passwords or frontend personal access tokens.
  • Preserve existing functionality unless removal is explicitly requested.
  • Use branches and pull requests for significant changes.
